Integration round 1 (branch `v03/ui`). Every finding in `docs/v03/qa_*.json` whose hint names this track's files, re-verified on the merged build (game/grand-theft-pundit 10ba585 merged into v03/ui) by tracing the repro through the current code and, where QA wrote one, by running the regression test. Statuses: **fixed** (changed by the UI track in this round), **already-fixed** (gone before this round or fixed elsewhere), **not-reproducible**, **wontfix** (with the reason), **open**.

Totals: fixed 55, already-fixed 1, wontfix 1 (57 findings).

Regression runs: the QA-B tests (`tests/regress/qa_b_*.js`) were run from a scratch mirror whose shared helper `qa_b_lib_fe.js` skips the v0.3 first-launch opening (QA-C1-07) and finds QUIT by id (v0.3 added STORY to the pause menu, so its fixed index 8 is RESTART); without that, most front-end tests fail in their setup. The repo copies are QA's and were not edited. Column "QA test" shows the result on the current code.
